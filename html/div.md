# DIV

**Data:** 29/09/2026  
**Tags:** #html

## O que aprendi

Aprendi que a tag `<div>` funciona como uma caixa ou grupo genérico.

Ela serve para agrupar elementos que quero organizar ou estilizar juntos.

```html
<div class="grid-projetos">
    <article>Projeto 1</article>
    <article>Projeto 2</article>
</div>
```

Nesse exemplo, a `<div>` agrupa os dois projetos.

A `<div>` não organiza os elementos sozinha. O CSS define como eles serão exibidos e organizados.

## Resumo

`<div>` é uma caixa genérica usada para agrupar elementos.
