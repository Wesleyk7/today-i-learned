# DIV

**Data:** 29/09/2026  
**Tags:** #html

## O que aprendi

A tag `<div>` funciona como uma caixa ou grupo genérico.

Ela serve para agrupar elementos que eu quero organizar ou estilizar juntos.

Exemplo:

```html
<div class="grid-projetos">
    <article>Projeto 1</article>
    <article>Projeto 2</article>
</div>
