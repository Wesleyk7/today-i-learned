# Meta Viewport

**Data:** 21/09/2026  
**Tags:** #html #responsividade

## O que aprendi

Aprendi que a tag `meta viewport` ajuda o navegador a adaptar a página ao tamanho da tela do dispositivo.

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

`width=device-width` faz a largura da página acompanhar a largura do dispositivo.

`initial-scale=1.0` define o zoom inicial como 100%.
