# Span

**Data:** 29/09/2026  
**Tags:** #html

## O que aprendi

Aprendi que a tag `<span>` serve para envolver uma pequena parte de conteúdo.

Usei `<span>` para mostrar as tecnologias e aprendizados dos meus projetos.

```html
<div class="aprendizados">
    <span>HTML</span>
    <span>CSS</span>
    <span>JavaScript</span>
</div>
```

Cada `<span>` representa uma pequena informação.

Depois posso estilizar todos eles com CSS.

```css
.aprendizados span {
    background-color: #222222;
    color: white;
}
```

A `<div>` agrupa os elementos e cada `<span>` representa um item individual dentro dela.

## Resumo

`<span>` é usado para pequenos trechos ou informações dentro do HTML.
