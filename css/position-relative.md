# Position Relative

**Data:** 25/09/2026  
**Tags:** #css

## O que aprendi

Aprendi que:

```css
position: relative;
```

permite movimentar um elemento em relação à posição original dele.

Exemplo:

```css
.elemento {
    position: relative;
    left: 50px;
}
```

Nesse exemplo, o elemento se move 50px para a direita a partir da posição original.

Também posso utilizar:

```css
top: 20px;
right: 20px;
bottom: 20px;
left: 20px;
```

Mesmo sendo movimentado, o espaço original do elemento continua reservado na página.

## Resumo

`relative` permite movimentar um elemento tomando como referência a posição original dele.
