# Align Self

**Data:** 29/09/2026  
**Tags:** #css #flexbox

## O que aprendi

Aprendi que `align-self` controla o alinhamento de um item específico dentro de um Flexbox.

No meu projeto utilizei:

```css
.link-projeto {
    align-self: center;
}
```

Nesse exemplo, o próprio link fica centralizado dentro do card.

Também aprendi a diferença entre:

```css
text-align: center;
```

e:

```css
align-self: center;
```

`text-align: center` centraliza o texto.

`align-self: center` centraliza o próprio elemento dentro do Flexbox.

A palavra `align` significa alinhar e `self` significa "si mesmo".

## Resumo

`align-self` controla o alinhamento individual de um elemento dentro do Flexbox.
