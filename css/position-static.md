# Position Static

**Data:** 25/09/2026  
**Tags:** #css

## O que aprendi

Aprendi que:

```css
position: static;
```

é o posicionamento padrão dos elementos.

Exemplo:

```css
.elemento {
    position: static;
}
```

O elemento continua seguindo normalmente a ordem definida pelo HTML.

Ele permanece no fluxo normal da página.

## Resumo

`static` é o posicionamento padrão e mantém o elemento seguindo normalmente o fluxo da página.
