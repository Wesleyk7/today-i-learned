# Responsividade com Media Query

**Data:** 21/09/2026  
**Tags:** #css #responsividade #mediaquery

## O que aprendi

Hoje aprendi que posso usar `@media` para alterar o estilo da página dependendo do tamanho da tela.

Exemplo:

```css
@media (max-width: 600px) {
    /* Estilos para telas menores */
}
```

Nesse exemplo, as regras dentro do `@media` serão aplicadas quando a tela tiver até 600px de largura.

Isso é útil para adaptar um site para celulares.
