# Seletores CSS

**Data:** 21/09/2026  
**Tags:** #css #seletores

## O que aprendi

Aprendi que posso selecionar um elemento que está dentro de outro elemento no CSS.

Exemplo:

```css
footer p {
    margin: 0;
    color: white;
}
```

Nesse exemplo, `footer p` seleciona os elementos `<p>` que estão dentro do `<footer>`.

## HTML utilizado

```html
<footer>
    <p>© 2026 Wesley - Meu portfólio</p>
</footer>
```
